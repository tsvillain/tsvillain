## 🤖 AI engineering
 
Small, focused tools for the parts of LLM apps that break in production.
 
- **[deprecation-mcp](https://github.com/tsvillain/deprecation-mcp)**: an MCP server that tells an agent whether a vendor API or SDK is active, deprecated or sunset, so upgrade work checks before it breaks instead of after.
- **[rag-latency-profiler](https://github.com/tsvillain/rag-latency-profiler)**: runs one full RAG cycle, measures the metrics that matter for LLM apps, and shows with a failing case why `200 OK` is not a health signal.
- **[Agent Eval](https://github.com/tsvillain/Agent-Evaluation)**: LLM-as-judge evaluation, so you can tell whether a prompt or model change made your agent better or worse.
- **[research-agent](https://github.com/tsvillain/research-agent)**: a Plan → Research → Write → Review multi-agent pipeline with Zod-validated structured outputs.
- **[groundwork](https://github.com/tsvillain/groundwork)**: an Agent Skill for Claude Code, Codex and Cursor. Plan a project once, then pick it up where you left off.
